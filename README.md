# PnP Sheet Printer – Releases

Foundry-VTT-Modul (v14, dnd5e 6.0.x), das Charaktere live aus Foundry in ausfüllbare **PDF-Charakterbögen** druckt – für das analoge Spiel am Tisch. Mitgeliefert wird der **Heldenbogen 5E** in vielen Fassungen: v3 Klar, Erste Schritte, Tiefwasser, Undermountain, 13 Klassenbögen (auch automatisch nach Hauptklasse), außerdem Feldbuch und Codex (je mit Druckversion), Tablet und Handy (je Tag/Nacht) sowie v1 Pergament. Außerdem der **Charakterbogen 5e von André Tändler**. Der offizielle Standard-Charakterbogen (DE/EN) lässt sich als eigene PDF einbinden.

Dieses Repository enthält nur die installierbaren Pakete.

## Installation

Foundry-Setup → **Add-on-Module** → **Modul installieren** → bei **Manifest-URL** eintragen:

```
https://raw.githubusercontent.com/dave-bp/pnp-sheet-printer-releases/main/module.json
```

Danach in der Welt unter **Einstellungen → Module verwalten** aktivieren. Gedruckt wird über das Fenstermenü des Charakterbogens oder per Rechtsklick auf den Charakter in der Akteure-Liste → **Bogen drucken**.

### Standard-Charakterbogen

Der offizielle ausfüllbare Charakterbogen ist aus Urheberrechtsgründen nicht enthalten. Moduleinstellungen → **Standard-Charakterbogen (deutsch): PDF** → PDF hochladen bzw. auswählen; danach erscheint er im Druckdialog.
